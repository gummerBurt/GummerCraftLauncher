# Установка для Linux і Steam Deck

`GummerCraft-Linux.desktop` завантажує і запускає [`install.sh`](install.sh): він ставить лаунчер з власною Java в `~/GummerCraft/app` без терміналу і прав root, додає ярлики в меню програм і на робочий стіл, а якщо на комп'ютері є Steam, то ще і ярлик GummerCraft у бібліотеку Steam з обкладинками і розкладкою геймпада. Повторний запуск того самого файлу дописує, чого бракує; збірки і світи лишаються. Що саме і куди пишеться, описано в [SECURITY.md](../../SECURITY.md).

Steam переписує свої файли зі своєї пам'яті, тому ярлик і розкладка пишуться лише при закритому Steam: якщо Steam відкритий, установка питає дозволу закрити його на кілька секунд і потім відкриває знову.

## Керування геймпадом на Steam Deck

Steam ставить розкладку на ярлик, а гра запускається з лаунчера і йде під його ярликом. Тому розкладка одна на лаунчер і на гру: ігрова (клавіатура і миша), а лаунчер у Steam читає ті самі кнопки як навігацію. Установка ставить її сама, якщо гравець ще не вибрав для ярлика свою.

| Кнопка | У грі (Minecraft, StalDayZ) | У лаунчері |
|---|---|---|
| лівий стік | ходьба (W A S D), натиск: біг (Ctrl) | стрілки |
| правий стік, правий тачпад | камера / миша, натиск стіка: вид від третьої особи (F5) | курсор миші, натиск тачпада: клік |
| R2 / L2 | удар, постріл / використати, приціл (ліва / права кнопка миші) | лівий / правий клік |
| A | стрибок (пробіл) | натиснути |
| B | присісти (Shift) | назад (як Esc) |
| X / Y | інвентар (E) / перезарядка (R) | |
| L1 / R1 | слот на панелі (коліщатко миші) | прокрутка |
| ☰ / ⧉ | меню (Esc) / список гравців (Tab) | ☰: назад (Esc) |
| лівий тачпад натиском | вгору: чат (T), вниз: обвіси (Z), ліворуч: приціл (V), праворуч: огляд зброї (H) | |
| задні L4 / R4 | викинути (Q) / друга рука (F) | |
| задні L5 / R5 | режим вогню (G) / ліхтар (L) | |
| хрестовина | | стрілки |

Клавіші взято з налаштувань модпака StalDayZ; у звичайному Minecraft зайві (перезарядка, обвіси, режим вогню, ліхтар) просто нічого не роблять. Навігація по лаунчеру з геймпада вмикається лише на Linux, коли лаунчер запущено зі Steam або в ігровому режимі; на Windows і macOS лаунчер поводиться як завжди.

Свою розкладку можна вибрати в Steam як для будь-якої гри: кнопка керування на сторінці GummerCraft, «Шаблони», «GummerCraft (лаунчер та ігри)» або будь-яка інша. Свій вибір гравця повторна установка не змінює.

## Файли

- [`install.sh`](install.sh): установка (вона ж створює `steam-shortcut.py`, `steam-art.sh`, `uninstall.sh` у `~/GummerCraft/app`).
- [`steam/`](steam): обкладинки для бібліотеки Steam (генератор `make.py`) і розкладка геймпада `gummercraft_neptune.vdf` (генератор `make_input.py`: розкладку правити там, потім запустити `python tools/linux/steam/make_input.py`).
