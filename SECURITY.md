# Безпека та приватність

Цей документ описує, з якими серверами з'єднується GummerCraft Launcher, що він зберігає на комп'ютері і які в нього відомі обмеження. Усе нижче можна перевірити у вихідному коді цього репозиторію.

## Повідомити про вразливість

Пишіть команді напряму через [gummercraft.fun/support](https://gummercraft.fun/support) і не публікуйте деталі, доки ми не випустимо виправлення.

## Мережеві з'єднання

Усі з'єднання - HTTPS з повною перевіркою сертифіката й імені сервера. Для старих версій Java 8, де бракує нових кореневих сертифікатів, лаунчер додає до системного сховища кілька офіційних кореневих CA (`launcher-shared/.../tls/extra-roots.pem`, клас `TrustedTls`); перевірка від цього не послаблюється.

| Адреса | Навіщо | Що надсилається |
|---|---|---|
| `cdn.gummer.cc/launcher/install/release.json`, `/launcher/install/versions/*.jar` | перевірка та завантаження нової версії лаунчера: бутстрапер (exe) звіряє версію при кожному запуску й одразу качає новішу, без інтернету запускає встановлену | нічого; якщо в `release.json` є `sha256`, завантажений jar звіряється з ним |
| `cdn.gummer.cc/launcher/news/public.html` | сторінка новин | версія лаунчера |
| `cdn.gummer.cc/v1/packages/manifest.json` | список збірок | бета-ключ із налаштувань (порожній, якщо не введений) |
| `cdn.gummer.cc/v1/packages/...`, `cdn.gummer.cc/v1/runtime/...` | файли збірок і Java-рантайми (Eclipse Temurin), з перевіркою контрольних сум | нічого |
| `launchermeta.mojang.com`, `piston-meta.mojang.com`, `piston-data.mojang.com`, `libraries.minecraft.net`, `resources.download.minecraft.net` | файли Minecraft від Mojang | нічого |
| `maven.minecraftforge.net`, `maven.fabricmc.net`, `meta.fabricmc.net`, `meta.quiltmc.org` | завантажувачі модів | нічого |
| `login.microsoftonline.com` (у вашому браузері), `login.live.com`, `user.auth.xboxlive.com`, `xsts.auth.xboxlive.com`, `api.minecraftservices.com` | вхід через Microsoft | дані входу - тільки серверам Microsoft / Xbox / Mojang |
| `textures.minecraft.net` | голова скіна для списку акаунтів | нічого |
| `logs.gummercraft.fun` | **тільки** після натискання «Завантажити лог» у консолі | текст консолі; токен доступу, UUID і Session ID вирізаються перед відправкою (`MessageLog.getPastableText`) |
| `launch.gummercraft.fun/install/java` | **тільки** якщо exe не знайшов Java: відкривається у браузері й переадресовує на офіційне завантаження Java | нічого |
| `go.gummer.cc/out/*` | кнопки Discord / Telegram / сайт / вікі в бічній панелі, відкриваються у браузері | нічого |

Телеметрії та ідентифікаторів пристрою немає. Інших з'єднань лаунчер не робить; гра після запуску працює як звичайний Minecraft.

## Акаунти

- **Пароль Microsoft лаунчер не отримує.** Вхід відбувається у вашому браузері на сторінці Microsoft; лаунчер отримує лише одноразовий код через тимчасовий локальний порт (`localhost`) і обмінює його на токени на серверах Microsoft (`MicrosoftWebAuthorizer`, `MicrosoftLoginService`).
- Токени зберігаються **лише локально** у файлі `accounts.dat` і нікуди не відправляються, окрім серверів Microsoft / Mojang. Токен доступу передається тільки процесу гри, а в логах маскується.
- Локальні (офлайн) акаунти - це просто нікнейм, без пароля й без входу.
- Старий вхід Mojang за паролем (з оригінального SKCraft) надсилає пароль тільки на `authserver.mojang.com`; Mojang цей сервіс вимкнула.
- Щоб вийти, видаліть акаунт у лаунчері; доступ застосунку можна також відкликати в налаштуваннях акаунта Microsoft.

## Файли та система

- Усі дані - в одній робочій папці (`Документи\GummerCraft` на Windows).
- Реєстр Windows лаунчер **лише читає** (пошук встановленої Java у `WindowsRuntimeFinder`). Автозапуску, служб, задач планувальника, правил брандмауера чи ярликів він не створює.
- DLL у робочій папці - це native-бібліотеки Minecraft від Mojang (LWJGL тощо), файли Java-рантайму Eclipse Temurin, підписані Eclipse Foundation, і `launcher/natives/flatlaf-windows-*.dll` - службова бібліотека інтерфейсу [FlatLaf](https://www.formdev.com/flatlaf/native-libraries/) (вигляд вікна), яка лежить у самому jar лаунчера.
- Сандбокси на кшталт Hybrid Analysis можуть показувати для лаунчера «підозрілі» індикатори: зміну прав папки `%ALLUSERSPROFILE%\Oracle\Java\.oracle_jre_usage` через `icacls` (так робить сама Oracle Java 8 для будь-якої Java-програми) і автоматичні співставлення назв системних функцій Java з техніками MITRE. Це не дії лаунчера.

## Відомі обмеження

1. `accounts.dat` лише «скремблюється» фіксованим ключем (успадковано від SKCraft), а не шифрується по-справжньому. Програма, що вже має доступ до вашого ПК, може прочитати з нього токени - як і у більшості лаунчерів.
2. Exe-обгортка бутстрапера (Launch4j: jar усередині exe) може викликати хибні спрацювання антивірусів.

## Історія виправлень

- **1.29** - увімкнено повну перевірку HTTPS-сертифікатів (раніше вона була вимкнена як обхідне рішення для старих Windows/Java, що в незахищених мережах дозволяло перехоплення з'єднань лаунчера); завантаження лаунчера тільки по HTTPS і з перевіркою SHA-256; exe при запуску одразу ставить новішу опубліковану версію; лог консолі - по HTTPS; бібліотека інтерфейсу більше не розпаковується в `%TEMP%`; прибрано невикористаний ідентифікатор `uuid` з налаштувань.
